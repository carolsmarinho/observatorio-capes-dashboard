# Observatório da Avaliação da CAPES — piloto

Dashboard público para acompanhar como a arquitetura, os critérios e os pesos da avaliação de programas de pós-graduação mudam entre ciclos.

**Escopo atual:** Psicologia, Química e Saúde Coletiva; ciclos 2017–2020, 2021–2024 e 2025–2028.

## Princípio do projeto

O site foi desenhado para que uma pessoa não familiarizada com as Fichas da CAPES consiga:

1. entender o que são quesitos, itens e pesos;
2. ler os critérios completos antes de ver as conclusões;
3. acompanhar o crosswalk semântico 2021–2024 → 2025–2028;
4. distinguir pesos exatos de limiares mínimos;
5. acessar as Fichas oficiais, os dados derivados e os limites de cada afirmação.

A pasta `data/` contém as saídas públicas e um README específico de proveniência.
